# Learning Objectives

By the end of this lesson you will be able to:

- Sign up and open Claude on the **web**, **desktop**, or **mobile**.
- Find your way around the interface: the **+ menu**, **slash commands**, the **model selector**,
  and **Settings**.
- Compare the **plans** (Free, Pro, Max, Team, Enterprise) and pick one that fits.
- Explain **five-hour session limits** and **weekly limits**, and what uses them up fastest.
- Apply habits that make your usage go further.

# Why It Matters

Knowing the app well is the cheapest upgrade there is. People who never open the **+** menu don't
know Claude can search the web, read their Google Drive, or build a slide deck. People who keep one
endless chat hit usage limits early and get worse answers. Ten minutes of orientation saves hours.

# Concept Explanation

### Signing up and where Claude runs

You need to be at least **18** and in a supported country or region. Then you can use Claude in three
places, all on the same account:

- **Web:** <https://claude.ai> in any modern browser.
- **Claude Desktop:** apps for **macOS** and **Windows**. The desktop app adds things the browser
  can't do, such as working with local files and folders, desktop extensions, and Claude Code in the
  **Code** tab.
- **Mobile:** apps for **iOS** and **Android**, good for quick questions, photos, and voice.

Your chats, Projects, and Artifacts sync across all three.

### A tour of the interface

- **The message box.** Type your request and send it. Paste or drag in files and images.
- **The + menu (or type `/`).** In the lower left of the message box. This is where you add files,
  turn on connectors and tools, start Research, and pick an output such as a doc or slides. Typing
  `/` opens the same options as commands.
- **The model indicator.** Below the message box on web and desktop (at the top on mobile). Click it
  to choose a **model**, an **effort** level, and whether **thinking** is on (Lesson 9). Changes apply
  from Claude's next response.
- **The sidebar.** Your chats, **Projects** (Lesson 7), the **Artifacts** tab (Lesson 6), and
  **Customize**, where skills, connectors, and plugins live (Lessons 12–13).
- **Settings** (click your initials). Highlights: **Capabilities** (code execution and file
  creation), **Memory** (Lesson 11), **Usage** (your limits), and privacy controls (Lesson 8). You can
  also set your preferred **language**. Claude works best in English but supports many others.

### The new "one conversation" experience

In September 2026 Anthropic began rolling out a unified experience to Pro and Max, called "Cowork
comes to every conversation." You don't have to choose between a quick chat and a bigger task first.
Ask for anything, from a one-line answer to a full report, spreadsheet, or presentation. Claude
decides whether a request needs a quick reply or a multi-step task (Lesson 14). The rollout is
gradual. If you still see separate **Chat** and **Cowork** options, you're on the classic layout,
and everything in this course works there too.

### The plans

As of writing (October 2026), from claude.com/pricing:

| Plan | Price | Who it's for |
| --- | --- | --- |
| **Free** | $0 | Trying Claude: chat on all apps, web search, file creation, memory, connectors, Artifacts |
| **Pro** | $20/month, or $17/month billed annually | Regular individual use: more usage, more models, Research, scheduled tasks, Claude Code, Cowork, Claude in Chrome |
| **Max** | From $100/month | Heavy users: 5x or 20x Pro's usage, priority at busy times, early features, monthly API credits |
| **Team** | Standard seat $25/month ($20 annual); Premium seat $125/month ($100 annual) | Small and mid-size teams: shared projects, admin controls, SSO, no training on your content by default |
| **Enterprise** | $20/seat/month billed annually (20-seat minimum) plus usage at API rates | Large organizations: spend limits, SCIM, audit logs, custom retention |

Prices and bundles change often, so check <https://claude.com/pricing> before you buy.

### How usage limits work

Claude doesn't count messages as a fixed number. It counts how much **work** your messages take.

- **Free** has a session limit that **resets every five hours**, and capacity varies with demand.
- **Paid plans** have a **five-hour session limit** plus **weekly limits**. **Settings > Usage** shows
  how much of the current session you've used and when it resets.
- On Pro and Max, limits are **shared across Claude and Claude Code**. Coding in the terminal draws
  from the same pool as chatting.
- When you hit a limit you can wait for the reset, upgrade, or (on Pro, Max, Team, and seat-based
  Enterprise) turn on **usage credits** to keep going.

The Help Center lists what uses more of your limit: **longer messages, bigger attachments, longer
conversations, tools (Research, web search), the model you choose, the effort level, creating
Artifacts, and multi-step tasks** such as running code or browsing.

# Key Terminology

- **claude.ai** — the web app; also where you manage your account.
- **Claude Desktop** — the macOS/Windows app; adds local files, desktop extensions, and Claude Code.
- **+ menu** — the button in the message box that opens files, tools, connectors, and outputs.
- **Model selector** — where you pick the model, effort level, and thinking setting.
- **Session limit** — how much you can use Claude in a rolling five-hour window.
- **Weekly limit** — a second cap on paid plans that resets each week.
- **Usage credits** — optional pay-as-you-go usage once you reach your plan's limit.

# Options and Trade-offs

| Surface | Best at | Limitations |
| --- | --- | --- |
| Web (claude.ai) | Everything chat-based, from any computer | No local file access or desktop extensions |
| Desktop app | Local files and folders, desktop extensions, Claude Code, local Cowork tasks | Must be installed; some tasks need it open |
| Mobile app | Quick questions, photos, voice, on the go | Research searches only the web there; some settings change only on web/desktop |

# Worked Example

**Scenario:** Priya is a freelance marketer. She drafts copy about two hours a day, analyzes a few
spreadsheets a week, and occasionally needs deep competitor research.

1. **Free** is enough to try Claude, but its five-hour session limit and lack of Research and
   Projects will slow her down.
2. **Pro** adds Projects (one per client, holding brand guides), Research, and more usage. It's the
   natural starting point.
3. She watches **Settings > Usage** for two weeks. If she regularly runs out mid-afternoon, **Max**
   (5x Pro's usage) is the next step. If she rarely does, Pro is right.
4. If she hires two contractors who need shared projects, **Team** becomes the better fit.

The habit that matters most is checking real usage before upgrading, instead of guessing.

# Real World Analogy

Usage limits work like a **refilling water tank**. Every task drains some water. A quick question is
a sip, while a long conversation with big files and Research fills a bucket. The tank refills on a
five-hour cycle, and paid plans also have a weekly ceiling on how much it can refill. Bigger plans
have bigger tanks. You make the water last by not filling buckets when a cup would do, and by
starting fresh glasses (new chats) instead of carrying around one giant, ever-heavier pail.

# Examples

## Example 1 — Basic: your first useful chat

```text
I just started using Claude. In 5 bullet points, tell me what you can help me with
as a high-school chemistry teacher, with one concrete example prompt for each.
```

**Why this works:** it tells Claude who you are and asks for examples you can try straight away. It's
a fast way to discover what's useful for *you*.

## Example 2 — Real-world: a usage-friendly working session

Instead of five separate messages, batch related requests into one:

```text
Here is my draft newsletter (pasted below). Please do three things:
1. Fix grammar and spelling.
2. Suggest 3 alternative subject lines.
3. Flag any sentence over 25 words.

<draft>
...
</draft>
```

**Why this works:** the Help Center's usage tips recommend batching similar requests and giving
background up front. One clear message does the work of several and saves back-and-forth.

## Example 3 — Pitfall: one conversation for everything

A user keeps a single chat open for weeks, covering recipes, then tax questions, then code. Each new
message drags the whole history along, so responses slow down, usage drains faster, and Claude gets
distracted by old, unrelated context.

**The fix:** start a **new chat for each new topic**. Keep long-lived reference material in a
**Project** instead (Lesson 7).

# Common Mistakes

- **Never opening the + menu.** Web search, connectors, Research, and file outputs all live there.
- **One endless chat.** Long conversations use more of your limit and blur Claude's focus.
- **Upgrading on a hunch.** Check **Settings > Usage** for a couple of weeks first.
- **Forgetting limits are shared.** Heavy Claude Code use draws from the same pool as your chats.
- **Using the most powerful settings for trivial tasks.** High effort and the largest model cost more.

# Best Practices

- Install the **desktop app** if you work with local files, and the **mobile app** for on-the-go use.
- Learn the **+ menu** and the **`/` commands**; that's where Claude's tools are.
- **Batch related asks** into one well-structured message, and give background up front.
- Start **new chats for new topics**, and use **Projects** for material you reuse.
- Check **Settings > Usage** before you upgrade, and pick the plan your real usage justifies.

# Summary

- Claude runs on the **web**, **desktop** (macOS, Windows), and **mobile** (iOS, Android), all synced.
- The **+ menu** (or `/`) opens tools and outputs; the **model indicator** sets model, effort, and
  thinking.
- Plans range from **Free** to **Pro**, **Max**, **Team**, and **Enterprise**; prices change, so check
  the pricing page.
- Paid plans have **five-hour session** and **weekly** limits, **shared with Claude Code**; Free has a
  five-hour session limit.
- Long chats, big files, tools, bigger models, and higher effort use more of your limit.

# Flash Cards

Q: Where do you find Claude's tools, like web search, connectors, and Research?
A: In the + menu in the lower left of the message box, or by typing / in the message box.

Q: What two kinds of usage limits do paid plans have?
A: A five-hour session limit and weekly limits.

Q: Are Claude and Claude Code usage counted separately on Pro and Max?
A: No. The limits are shared, so all activity in both counts against the same limits.

Q: Name four things that use more of your usage limit.
A: Long messages and attachments, long conversations, tools like Research and web search, bigger models, higher effort, Artifacts, and multi-step tasks (any four).

Q: What can the desktop app do that the web app can't?
A: Work with local files and folders, run desktop extensions, run Claude Code in the Code tab, and run local Cowork tasks.

Q: Where can you check how much of your current session you've used?
A: Settings > Usage.

# Exercises

### Easy
Open **Settings > Usage** and note how much of your current session you've used and when it resets.
Then open the **+** menu and list every option you see.

### Medium
For one week, write down each time you start a chat and what it was for. At the end of the week,
count how many could have been batched together or should have been separate chats. Adjust your
habits accordingly.

### Challenging
Write a one-page recommendation for a 12-person nonprofit choosing between Pro for everyone, Team,
and Enterprise. Cover cost, shared projects, admin controls, and data privacy, citing the current
pricing page. Note which facts you'd re-check before presenting it.
